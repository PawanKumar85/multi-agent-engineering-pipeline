# Deployment

Prepare release checklist, environment requirements, rollout and rollback steps; require human approval before production actions.

1. Read approved upstream artifacts and requirement IDs.
2. Identify missing inputs and block rather than inventing facts.
3. Produce the stage output in `docs/` with explicit assumptions, evidence, and next-stage handoff.
4. Respect human approval gates and report status honestly.
